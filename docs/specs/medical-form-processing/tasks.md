  - Type classify; zoning; printed OCR; validation; JSON results

- Phase 4 — Observability & Active Learning
  - Metrics dashboards; sampling of low-confidence fields; correction UI hooks
- Phase 5 — Hardening
  - Performance tuning; template versioning; privacy reviews (HIPAA/BAA)
