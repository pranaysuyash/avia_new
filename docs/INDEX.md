# Documentation Index

This directory centralizes documentation and planning artifacts for the media platform.

- Review & Plans
  - REVIEW_FINDINGS_SUMMARY.md — consolidated findings and candidate tasks (root)
  - API_INTEGRATION_AUDIT.md — API vs. frontend integration mapping (root)
  - KIRO_TASKS_GAP_AUDIT.md — gaps/opportunities (root; .kiro untouched)
  - MEDIA_PLATFORM_EXPANSION_PLAN.md — phased non-KIRO roadmap (root)
- WebSocket Endpoints
  - WS_ENDPOINTS.md — authoritative list of supported WS routes vs. client references
- Decision Records (ADRs)
  - adr/ADR_TEMPLATE.md — template for decisions
  - adr/ (place ADRs here, e.g., 0001-api-canonicalization.md)
- Task Logs
  - task-logs/TASK_LOG_TEMPLATE.md — per-task log template
  - task-logs/ (store dated logs per task)

Conventions
- Keep docs lightweight and actionable.
- Link to files/paths instead of duplicating content.
- Use ADRs for decisions with lasting impact.
