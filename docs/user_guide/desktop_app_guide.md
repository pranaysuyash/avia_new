# Desktop Application User Guide

This guide provides a detailed walkthrough of the desktop application's features and how to use them.

## Table of Contents

- [Installation](#installation)
- [Getting Started](#getting-started)

## Installation

To install the desktop application, download the latest release for your operating system from the [releases page](https://github.com/your-repo/releases).

## Getting Started

Once you have installed the application, you can launch it from your applications folder.

The desktop application provides the same features as the web application, but with the convenience of a native desktop experience.

## Features

The desktop application includes all the features of the web application, including:

-   **Multi-Modal Transcription**: Transcribe audio and video files (MP3, WAV, MP4, M4A).
-   **Advanced Analysis**: Named Entity Recognition (NER), sentiment analysis, and more.
-   **Speaker Diarization**: Identify and separate different speakers in the audio.
-   **Multi-Language Support**: Transcribe and analyze content in over 50 languages.
-   **Collaboration Tools**: Team workspaces, real-time annotations, and version control.
-   **Enterprise-Ready**: Secure, scalable, and extensible with a full-featured REST API.

For a full list of features, see the [Web Application User Guide](web_app_guide.md).
