# Mobile Application User Guide

This guide provides a detailed walkthrough of the mobile application's features and how to use them.

## Table of Contents

- [Installation](#installation)
- [Getting Started](#getting-started)

## Installation

To install the mobile application, download the latest release for your operating system from the [releases page](https://github.com/your-repo/releases).

## Getting Started

Once you have installed the application, you can launch it from your app drawer.

The mobile application provides a subset of the features available in the web and desktop applications, optimized for a mobile experience.

## Features

The mobile application includes the following features:

-   **Multi-Modal Transcription**: Transcribe audio and video files (MP3, WAV, MP4, M4A).
-   **Advanced Analysis**: Named Entity Recognition (NER), sentiment analysis, and more.
-   **Speaker Diarization**: Identify and separate different speakers in the audio.
-   **Multi-Language Support**: Transcribe and analyze content in over 50 languages.

For a full list of features, see the [Web Application User Guide](web_app_guide.md).
