# 2025 H1 Roadmap (Proposed)

## Tracks (Top 5)

1) Pipeline & Template Builder (Q1→Q2)
- Why: Composable workflows multiply value across verticals; unlocks reuse.
- Scope (H1): Canvas editor MVP → templates/versioning → compile/run → observability → policies.
- Milestones: M1 (Editor+Catalog), M2 (Templates+Manifest), M3 (Compile+Run+Triggers), M4 (Observability+Guardrails).
- Metrics: Pipelines created/run; time-to-first-value; failure rate; rerun usage.
- Impact: +Velocity, +Retention, +Cross-sell (templates library).

2) Frame OCR Indexing (Q1)
- Why: Immediate search expansion for non-transcribed video; clear differentiator.
- Scope: Interval sampling, OCR, hits index, search integration, UI time-jump.
- Metrics: OCR coverage, accuracy, search CTR from OCR results.
- Impact: +Discovery, +Engagement; supports broadcast/news/education/legal.

3) Creator Publish Packs (Q1→Q2)
- Why: High adoption for creators; bundles multiple features into one-click value.
- Scope: Thumbnails/B‑roll generation (provider hub), title/desc/hashtags, caption burn-in presets, multi-platform export.
- Metrics: Packs created, publish rate, A/B uplift.
- Impact: +Acquisition, +GMV via marketplace tie-ins.

4) Education Learning Augmentation (Q2)
- Why: Student/educator workflows broaden market; builds on transcripts/OCR.
- Scope: Study packs (flashcards/quizzes), time-coded notes, slide OCR, LMS exports.
- Metrics: Study packs generated, export usage, engagement uplift.
- Impact: +New vertical, +Retention; upsell to institutions.

5) Live/SSAI & Highlights Suite (Q2)
- Why: Sports/news/live events require real-time capabilities.
- Scope: Live captions/translation, highlight detection, SSAI metadata, DVR search.
- Metrics: Latency SLAs, highlights generated, SSAI adoption.
- Impact: +Enterprise deals in media/sports; platform stickiness.

## Enablers
- WS endpoints consolidation; API prefix standardization; auth refresh consistency.
- Observability & cost guardrails; RBAC policies; design system accessibility.
