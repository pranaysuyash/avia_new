# Contributing

We use the Intent-First methodology to ensure work delivers clear user/business value with managed risk.

## How to Contribute
1. Start with an Intent Summary and quick Context Discovery.
2. Evaluate Value, Risk, Effort; choose an action via the Decision Matrix.
3. Prefer MVP completion for high-value, low–medium effort work.
4. Document deferrals in Tech/Test Debt with a proposed check-in.
5. Use ADRs for notable decisions.
6. In PRs, include: Intent Summary, Decision & Scope, MVP tests, and traceability links.

## Tests (MVP Rule for critical/high priority)
- Cover happy path, one high-impact failure, and any compliance/security constraint.

Thank you for contributing with intent.
